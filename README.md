# Jind

Jind is a simple and lightweight stop motion animation program written in Rust using Tauri and Yew. It is named after Maharani Jind Kaur, the last Queen of Panjaab. 

### Key features
- Autosave after every change
- Save to single project file -- not a folder
- Tiny binary size since there is not an entire web browser bundled with the application (crazy concept)
- Lower memory usage than comparable alternatives
